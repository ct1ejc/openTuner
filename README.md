Using the open-source code from fellow ham radio operator ZR6TG, I made some modifications to the program to improve certain aspects.
OpenTuner was tested with the Pico Tuner hardware (Minitiouner Variants).
The complete program is available on the website.

http: //ct1ejc.dynip.sapo.pt/forum1/conteudo/programasgratis/Opentuner.zip

For this program to work, you must download it from the website at the link above.

On your PC, create a folder with a name of your choice and download all the files into it. Run the opentuner.exe file.

The program is protected by Avast antivirus and is free of viruses.

To select a station on TUNER1 or TUNER2:
Right-click next to "Change frequency." Select the desired frequency from the list, then click the left mouse button.

Video recording:
Open the main/settings window and, under "Media Video Path," select a path within the directory where the program is installed.
For example, you can choose the "Videos" folder included within the program's directory. You may also keep the default setting.
Click "(R) Record" on TUNER1 or TUNER2.
